\begin{abstract}
We compare a block-diffusion model with an autoregressive baseline on
production log parsing under matched quality. The diffusion arm halves
median latency per event while filling every required field, and the gap
holds across seeds and input lengths. We state the regime, the comparison,
and the limits.
\end{abstract}
